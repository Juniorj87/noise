noise docs

noise (NOISE HUB) is one non-custodial interface for the Sui ecosystem: capital overview, discovery, swap, earn, staking, lending, liquidity, trading, bridge, automation, AI — with every action tracked in Activity. Last updated: 2026-09-30.

Honesty rule: every feature is labelled LIVE, READ ONLY, DEEP LINK or COMING SOON. Indicative values carry * and never look live.

How it works

Connect → Discover → Choose → Review → Sign → Track → Automate
Backend prepares. Wallet signs. Sui network settles.

Open the app, connect a Sui wallet (read-only address or wallet-standard), see Capital aggregated without double counting, pick an action, review provider + route + fees + risks, simulate where supported, sign in your wallet, track the digest in Activity.

Capital

Wallet coins (suix_getAllBalances), USD via CoinGecko, staking (suix_getStakes), non-coin object count (suix_getOwnedObjects). Rule: deposited tokens are positions, not wallet balance. Total = Available + DeFi + Staked + Rewards − Borrowed. Unpriced assets show Price unavailable.

Discover

Tokens, pools, protocols, opportunities — each with Source + Updated. Tabs filter the live table and opportunity cards. Pool/whale feeds are READ ONLY until the indexer milestone (STATUS.md).

Swap

Quotes via Cetus Aggregator V3 (router_v3/find_routes, SDK @cetusprotocol/aggregator-sdk@1.7.3). Review shows: you pay / receive, provider (Best route via Cetus), route, price impact, slippage, protocol / platform / network fees, minimum received, quote timestamp. No route → PROVIDER_UNAVAILABLE + deep-link, never a fabricated number.

Earn

Opportunities show asset, protocol, APY + timestamp, TVL where available, deposit/withdraw, fees, lock and withdrawal conditions, risks. * = indicative preview until the indexer; verify on provider.

Mandatory disclosure: your funds are deposited into the selected protocol's smart contracts. noise does not custody these funds. APY is variable and may change. Third-party protocol and smart-contract risks apply.

Earn math

annual  = principal × APY
period  = principal × APY × days / 365
compounding only where the protocol actually compounds

Staking

Native SUI staking reads are LIVE (validators, principal). Shows validator/provider, APR/APY, commission, unbonding period, fees. Liquid staking (Aftermath / Haedal / Volo): stake SUI → receive provider LST. Transaction build = execution milestone.

Lending

NAVI / Suilend / Scallop markets: supply APY, borrow APY, liquidity, utilization, collateral factor, liquidation threshold, health factor, rewards. Actions supply / withdraw / borrow / repay / claim follow the same Review → Sign flow. Never claim safe without current protocol data.

Liquidity

Add / remove / collect fees / inspect position, range, pool, fee tier, APR/APY where available. Impermanent loss only as a labelled model/estimate.

Trading

DeepBook: markets, bids/asks, spread, market/limit/cancel, open orders READ ONLY in this build; execution via DeepBook SDK milestone. Bluefin and others: DEEP LINK with attribution.

Bridge

Unified quote view (source, destination, asset, provider, fee, estimated receive, ETA) where provider APIs allow; otherwise DEEP LINK. No invented ETA/finality.

NFT

Wallet non-coin count is live. Buy/sell/list need a marketplace SDK — COMING SOON; use the marketplace directly.

Automation

Natural language → structured intent (schedule / price / reward / health triggers) → deterministic validation → permission engine → scheduler → adapter → simulation → execution → audit record. Default mode MONITOR + NOTIFY. Every execution automation carries allowed action/protocol/asset, max per execution, daily limit, expiration. Pause / resume / edit / revoke / delete anytime. Backend scheduler milestone moves runs off-device.

AI

Tool-based assistant over live hub data: capital, balances, positions, earn, staking, lending, pools, token, activity, rewards, compare, build, simulate. Every dynamic answer shows Source + Updated; never invents values. AI cannot touch keys, bypass permissions, or build arbitrary transactions:

User → AI → structured intent → validation → permission engine → tx builder → simulation → Review → wallet signs

Memory

Auto-save: UI preferences. Ask-before-save: strategies, notes, context. Never-save: seeds, keys, passwords, secrets. Enable / view / delete / clear in Security. Backend milestone: Seal-encrypted records in Walrus Memory.

Privacy

Seal = encryption & access control; Walrus = decentralized storage (blobs are public — private data is always Seal-encrypted first); Sui = settlement & execution.

Security

  • Non-custodial: backend prepares, wallet signs. Keys never requested, never stored.
  • Production data over Sui gRPC (unified SuiDataProvider); legacy JSON-RPC only as a local-dev fallback via third-party endpoints — never Foundation JSON-RPC in production.
  • Simulation before signing on every execution path; simulation_failed blocks the wallet prompt.
  • Automation limits, expiry, revoke, pause-all; security events log.
  • Mainnet/testnet strictly separated. Rate limits + caching on all provider calls.

We never claim 100% secure / unhackable / zero risk. Protocol, contract, liquidity and market risks always apply.

Fees

FeeMeaning
Protocol feeFee charged by the underlying protocol (e.g. DeepBook pool taker/maker, read per-market — never hardcoded)
Provider feeFee charged by the routing/execution provider (e.g. Aftermath router integrator share)
Noise Hub feeTransparent Noise Hub service fee — collected only as a real transaction leg; $0.00 when collection is not possible
Network feeSui transaction gas (estimated pre-sign, actual after confirmation)
Builder feeWhere the protocol supports it (DeepBook Predict official builder-code split — a share of protocol proceeds, never a trader debit)
Penalty / ImpactInstrument-specific Predict components, exact per market from the simulated chain quote

Referral rewards are funded from eligible Noise Hub platform revenue — never an extra charge. The fee recipient is server-side configuration (ACTION_HUB_FEE_RECIPIENT); without it the platform fee is disabled and displayed as $0.00. Revenue is recorded only after on-chain confirmation.

Referral

referralReward = eligiblePlatformFee × policyRate(protocol, action)
e.g. Aftermath perps: $1.00 × 10% = $0.10 · Cetus: 0% (no partner revenue)

No universal rate. Each protocol has a verified ReferralPolicy (default 0 until partner terms are confirmed). Links look like https://noisehub.xyz/?ref=bulka (custom code or generated). 30-day attribution window (configurable). Self-referral, circular, duplicates and fake volume blocked. The reward is a share of platform revenue — never an extra user fee — and is recorded only after a real revenue event.

DeepBook Predict

A binary instrument: pick an asset, a strike and an expiry, take UP (settles above strike) or DOWN (settles below). Settlement is automatic and on-chain. Quotes show the exact fee components from a simulated chain quote — premium, trading fee, subsidy, builder fee, penalty, inventory impact — plus gas. There is no separate Noise Hub debit on Predict: builder/referral revenue is a split of protocol proceeds, not a trader charge. Minimum premium 1.00 USDC, quantity lots of 0.01.

Activity

Every operation → timestamp, action, provider, asset, amount, fees, digest, status (preparing / awaiting signature / submitted / confirmed / failed / cancelled), origin (manual / automation / AI). Persisted server-side; digests link to the explorer.

FAQ

What is Noise Hub?

An execution + aggregation layer over existing Sui protocols: connect your wallet and act — swap, trade spot, take Predict positions, stake, track everything — with real quotes, real simulation and wallet signing.

Does Noise Hub custody my funds?

No. Your assets remain in your wallet and protocol positions. Transactions are signed by your wallet; the backend never holds keys and never signs.

How does Noise Hub make money?

On supported actions the hub may charge a transparent service fee, always shown before signing as Protocol / Provider / Noise Hub / Network lines. It is collected only as a real transaction leg — otherwise it reads $0.00.

Does referral increase my fee?

No. Referral rewards are paid from eligible Noise Hub platform revenue, never added to what you pay.

Who receives the Noise Hub fee?

The configured Noise Hub fee recipient (server-side configuration). It is never user input, never AI-supplied, never hardcoded in the frontend.

What happens if a transaction fails?

Simulation runs before signing — a failed simulation blocks the wallet prompt and nothing is sent. A wallet rejection submits nothing on-chain. On-chain failures are tracked to confirmed/failed with the reason shown in Activity.

Is Noise Hub a wallet?

No. It prepares and simulates; your wallet signs.

Can Noise Hub access my private key?

No. Keys never leave your wallet; the backend has no key handling at all.

What is DeepBook Spot?

The central-limit order book on Sui: live bids/asks per market, market and limit orders through your BalanceManager.

What is DeepBook Predict?

A binary instrument — asset, strike, expiry, UP/DOWN — with automatic on-chain settlement. Fees (trading, builder, penalty, impact) are quoted exactly per market from a simulated chain quote.

Why is a Predict fee different from a normal swap?

Predict mints a position against a market with its own fee policy (trading, builder, penalty, impact/subsidy components read from market state), while a swap pays router/pool fees plus gas. Both are shown line-by-line before you sign.

Is noise a wallet? Does it hold my funds?

No. It is a non-custodial execution layer. Funds sit in your wallet or in the protocol contracts you explicitly deposit into.

Where does APY come from?

Staking APY is live from the Aftermath Staking SDK; pool APR/TVL from the Aftermath Pools API — each with source + timestamp. Anything without a verified source shows Unavailable instead of a number. APY is always variable — verify on the provider before acting.

What happens if a provider is down?

Health monitoring isolates it (PROVIDER_UNAVAILABLE + deep-link). The rest of the app keeps working.

Which wallet do I need?

Any wallet-standard Sui wallet. Connection is read-only until you sign a reviewed transaction.
