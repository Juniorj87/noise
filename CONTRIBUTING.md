# Правила репозитория

1. **На GitHub — только необходимое.** Коммитятся продуктовые правки и их минимум. Временные файлы (`tmp-*`, скрипты-пробы, zip, логи) не коммитить — удалять до коммита.
2. **README — продуктовый.** Как работает, что работает, какие проекты подключены, открытый код, доступ к кошелькам и приватность. Без мануалов «как поднять свой сервер и открыть сайт».
3. **Не рекламировать нереализованное.** Ставки, доходности и возможности — только из живых чтений, ничего не выдумывать.
4. **Перед пушем:** `git status` + `git diff`, в stage только нужные файлы, без секретов и ключей.
